# Guide

The guide follows a repository from nothing to a site that CI builds:

- [Install](install.md) adds the shell and runs the first check.
- [Configuration](configuration.md) lists the few facts about the project the site needs.
- [Writing pages](writing.md) says what the site does with front matter, links, images and code.
- [Troubleshooting](troubleshooting.md) lists what to do when a check fails.

For what each command does, see the [reference](../reference/commands.md).
