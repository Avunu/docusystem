# Docusystem example documentation

This site is built from the Markdown in `docs/` and nothing else. The layouts, components, fonts, search and project switcher come from one package, `@avunu/docusystem`.

> [!NOTE]
> GitHub renders this callout too, because it is the standard alert syntax.

Start with [installing](guide/install.md), read about [configuration](guide/configuration.md) and [writing pages](guide/writing.md), or look up a [command](reference/commands.md). If something does not work, try [troubleshooting](guide/troubleshooting.md).

The source of this example is in its [repository](https://github.com/Avunu/docusystem-example): the stand-in application is [src/worker.ts](../src/worker.ts), and the project is released under the [MIT license](../LICENSE).
