# Getting started

This page takes you from nothing to a working install.

## Requirements

| Requirement | Version | Notes                           |
| ----------- | ------- | ------------------------------- |
| Git         | 2.40+   | Needed to clone the repository. |
| Node.js     | 22+     | Runs the command line tool.     |

> [!TIP]
> Put each topic in its own file and give folders a `README.md` that introduces them.

## Install

```bash
git clone https://github.com/Avunu/example.git
cd example
npm install
```

## Troubleshooting

> [!WARNING]
> Replace every `<PLACEHOLDER>` before you run a command.

See the [configuration options](guides/Configuration%20Options.md#options).
